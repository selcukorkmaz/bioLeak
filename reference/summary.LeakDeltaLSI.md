# Summarize a LeakDeltaLSI object

Prints a human-readable summary of the Delta LSI analysis comparing
leaky vs guarded evaluation pipelines.

## Usage

``` r
# S3 method for class 'LeakDeltaLSI'
summary(object, digits = 3L, ...)
```

## Arguments

- object:

  A `LeakDeltaLSI` object from
  [`delta_lsi`](https://selcukorkmaz.github.io/bioLeak/reference/delta_lsi.md).

- digits:

  Integer. Number of decimal places to show (default 3).

- ...:

  Unused.

## Value

Invisibly returns `object`.
